# 智能计划教练 (Smart Plan Coach)

一款个人计划管理工具，具备完整的激励系统。所有数据保存在浏览器 `localStorage` 中，无需后端。

## 功能

- **多计划并行**：同时管理多个独立计划（健身 / 学习 / 工作等）
- **AI 任务拆解**：输入目标自动生成月 / 周 / 日任务
- **每日执行反馈**：标记完成状态，进度条实时更新
- **动态调整**：根据每日完成率自动调整明日任务量（≥80% 加量 / 50–80% 持平 / <50% 减量）
- **三种挑战模式**：激进 / 稳健 / 保守
- **休息机制**：手动休息 + 连续未达标自动推荐 + 达标奖励半量日
- **激励系统**：日 / 周 / 月积分与称号、连击加成、积分兑换、称号墙
- **数据趋势**：近 14 日与周 / 月平均的 SVG 趋势图
- **移动端优先**：简洁卡片设计

## 使用

直接用浏览器打开 `index.html` 即可。建议首次点击「载入示例计划」体验。

## 部署为网页

1. 在仓库 **Settings → Pages → Source** 选择 `main` / `root`，保存后即可获得在线访问地址：
   `https://embarksun.github.io/smart-plan-coach/`
2. 也可以直接用 GitHub Pages、任意静态托管或本地打开 `index.html`。

## 技术

单文件 HTML（内嵌 CSS + JS），无任何外部依赖。
